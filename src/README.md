# 🐂 QurbaniHat | Livestock Booking Platform

A modern, responsive web application designed to simplify the process of browsing and booking livestock for the holy occasion of Qurbani.

## 🔗 Live Link
[View Live Site](https://qurbani-hat-sepia.vercel.app)

---

## 🎯 Purpose
The main goal of **QurbaniHat** is to bridge the gap between livestock sellers and buyers. It provides a seamless user experience for searching, sorting, and booking animals (Cows, Goats, etc.) from the comfort of home, ensuring a hassle-free Qurbani preparation.

---

## ✨ Features

*   **Dynamic Animal Listing:** Browse a wide variety of livestock with detailed information.
*   **Smart Sorting:** Users can sort animals by price (Low to High & High to Low) to find the best deals.
*   **Secure Authentication:** Integrated Google and Email-based login/register system using Better Auth.
*   **Interactive UI:** Modern Bento grid layouts and smooth hover effects for a premium feel.
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
*   **Real-time Notifications:** Instant feedback on user actions via Toast notifications.

---
